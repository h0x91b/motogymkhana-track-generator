# Out of Scope

- Правка отдельных конусов и свободная форма элемента: элемент остаётся экземпляром типа из каталога. Закрепление элементов с перегенерацией остальных. Ручная прокладка связок.
- Сохранённые в приложении трассы, ссылки, коды обмена, QR, общие пресеты (файл .json — ADR 0013).
- Несколько вариантов на один seed.
- Обязательный состав (заказ конкретных типов и количеств): есть только разрешённые типы.
- Лимиты инвентаря: ведомость только сообщает.
- Недоступные зоны, произвольные многоугольные площадки, сохранённые площадки.
- Генерация по целевому времени и оценка времени проезда.
- Режим «Тренировка, не на время» с упражнениями на баланс и медленную езду (доска, медленный коридор, медленный слалом, стоп-линия, стоялка) и готовые трассы GP (GP8, Rotations GP) как пресеты — запланированы отдельными этапами, пока не сделаны.
- Полная маркировка Adachi (жёлтые ворота, полосы вращения, оранжевые границы), пользовательские профили правил.
- Печатный лист A4/PDF, SVG.
- Режим одновременной езды нескольких участников.
- Заморозка старых версий генератора и одинаковые трассы по seed в разных браузерах (ADR 0009).
- Публикация на GitHub Pages в рамках разработки (только по отдельному согласию).
