# Швы

- **Главный шов — генератор:** `generateCourse(recipe, seed)` → канонические данные трассы. Через него проверяется почти всё, включая нормализацию рецепта и разбор seed на входе.
- **Тонкий второй шов — модель схемы расстановки:** `buildSetupSheet(course)`. Картинка — главный продукт, и её числа должны быть верными независимо от отрисовки.
- **Шов файла:** `courseDocument` / `readCourseFile` и `conesCsv`: файл открывается той же трассой, испорченный отвергается, в CSV каждый конус на своём месте.
- **Третий шов — раскладка:** `routeLayout(layout)` и функции правки. Через него проверяется всё, что делает «Правка», без браузера.
- Рендер, интерфейс и картинку как пиксели модульными тестами не покрываем.
