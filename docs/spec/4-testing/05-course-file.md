# Файл трассы

- Трасса, сохранённая в файл и открытая обратно, совпадает с исходной побайтно — и сгенерированная, и с правками (те же проблемы). Испорченный, чужой или более новый файл отвергается с фразой для пользователя. В CSV ровно по строке на физический конус, координаты совпадают с трассой, высоты и цвета сходятся с ведомостью, номера в элементе — с таблицей карточки.
- «Мои трассы» (`test/storage.test.js`, без DOM): сохранение, список по последнему изменению, переименование, дублирование, удаление (и какая трасса откроется после удаления открытой); автосохранение пишет запись открытой трассы, не переписывает неизменённую, имя без переименования следует за seed; отложенная запись делается один раз на серию изменений; перенос ключей прежней сборки; переполненная или недоступная память — фраза, сохранённое цело.
