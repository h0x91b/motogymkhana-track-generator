# Раскладка и правка

- **Эквивалентность генератору.** Раскладка сгенерированной трассы (все три формы, оба класса мотоцикла, с паровозиком и без) возвращает ту же трассу побайтно и без проблем.
- **Размеры.** У каждого типа на обоих концах каждого размера, на стороне и на диагонали, линия езды не ближе 0,5 м к конусам, а конусы не совпадают; шаг вверх и шаг вниз взаимно обратны; минимумы по классу мотоцикла выдержаны; поворот на диагональ и обратно размер не меняет.
- **Правки.** Сдвиг держит элемент на площадке; шестнадцать поворотов по 22,5° возвращают элемент на место; типы «только вдоль сторон» поворачиваются на 45°; введённый угол встаёт на ближайший поворот и даёт ту же трассу, что повороты по шагу; замена сохраняет место и направление въезда для всех 20 типов; вставка каждого типа на просторной площадке не даёт проблем; удаление оставляет последний элемент; ни одна правка не меняет исходную раскладку.
- **Проблемы.** Наложение, выход за отступ, чужая зона выката, связка без пути по правилам, самопересечение в паровозике, нет пути обратно в стартовую коробку — каждая называет настоящие элементы и связку, а её текст говорит, что сделать. Раскладка читается из хранилища обратно без потерь, испорченная отвергается.
- **Схема расстановки** строится для трассы с правками так же, как для сгенерированной.
- **Вне решётки** (ADR 0017). Каждый тип, повёрнутый на шаг: якорь на целых метрах, размеры те же, что вдоль ширины, расстояния между конусами те же, конусы в своей зоне; каждый тип в каждом из своих поворотов даёт схему и CSV без NaN; карточка даёт ΔX/ΔY от якоря, и по ней одной восстанавливаются все конусы; размерные линии идут вдоль или поперёк повёрнутой оси и называют истинную длину, кратную 0,5 м; CSV — точное место каждого конуса до 0,1 м; файл с таким элементом пишется версией 2 и открывается обратно, файл версии 1 открывается; полшага у типа «только вдоль сторон» и четверть шага у любого не читаются; сгенерированная трасса всегда на решётке.
