# Модуль 11: Файл трассы

11. **Файл трассы (ADR 0013).** Модуль `src/file/course-file.js`, без DOM.
    - `courseDocument(layout, {build, edited})` — документ: `format: "motogymkhana-course"`, `version` — самая старая версия, которая прочтёт файл: 1, а 2 — если хоть один элемент стоит вне решётки (ось с половинным шагом или диагональ у типа «только вдоль сторон», ADR 0019); эта сборка читает обе, `build`, `edited`, затем раскладка (`recipe`, `seed`, `elements`). Элементы пишутся у любой трассы, и у несдвинутой: seed повторяет трассу только в одной сборке (ADR 0009). `readCourseFile(text)` возвращает раскладку или ошибку-фразу для пользователя: не JSON, чужой формат, нет версии, версия новее этой сборки, элементы, рецепт или seed не читаются. Файл только с рецептом и seed (без `elements`) открывается как трасса, которую эта сборка генерирует для них.
    - `conesCsv(course)` — по строке на физический конус в порядке расстановки: старт, каждый элемент с конусами разворота связки после него, финиш. Колонки: №, где (элемент «N. Тип», связка, старт или финиш), № в таблице карточки, высота, цвет (синий — слева, красный — справа, у низкого «любой»), X и Y от опорного угла с точностью 0,1 м. Разделитель — точка с запятой, десятичная запятая, в начале BOM: так таблица с русской локалью сразу раскладывает по колонкам.
    - Интерфейс. В рецепте блок «Файл трассы»: «Сохранить .json», «Конусы .csv» (скачивание прямо по нажатию), «Открыть .json» (выбор файла); где устройство умеет делиться файлами такого типа — ещё «Отправить .json» и «Отправить .csv». Открытый файл ставит в форму свой рецепт и seed, а свои элементы — поверх сгенерированной трассы, как «↶»: если эта сборка по тому же seed строит другую трассу, показывается трасса из файла как трасса с правками; если не строит вовсе — трасса из файла всё равно показывается. Трасса с правками того же рецепта и seed, которую заменил файл, уходит в «↶». Ошибка файла пишется под кнопками.
    - Чтение выбранного и брошенного файла — одно: `readCourseUpload(file)` проверяет размер (не больше `COURSE_FILE_MAX`, 1 МБ), читает текст и передаёт его `readCourseFile`; вставленный текст идёт через `readCourseText(text)` с той же проверкой размера.
    - Перетаскивание. Файл .json, брошенный на любое место страницы, открывается как через «Открыть .json»; пока файл над страницей, видна подсказка «Отпустите, чтобы открыть трассу». Вставка (Ctrl/Cmd+V) вне полей ввода текста, начинающегося с `{`, открывает его как файл трассы. Ошибка пишется под кнопками, если рецепт открыт, иначе всплывает. На сенсорных устройствах остаются выбор файла и «Отправить»; строка «можно перетащить» видна только при мыши.
    - «Мои трассы» (`src/app/storage.js`). В рецепте под «Файлом трассы»: поле названия (пустое — «площадка · сложность · seed · дата») и «Сохранить» кладут документ показанной трассы (`courseDocument`, как в .json) со временем сохранения под ключ `motogymkhana-constructor:courses:v1`. Список — новые сверху; нажатие на строку открывает трассу как файл, с правками; у строки «Переименовать», «Скачать .json», «Удалить» (с подтверждением в самой строке). Нехватка места или недоступная память — фраза под полем, сохранённое не теряется; `localStorage.clear()` не вызывается. Последняя форма и последняя правка запоминаются, как прежде.
