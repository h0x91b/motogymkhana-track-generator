# Модуль 11: Файл трассы

11. **Файл трассы (ADR 0013).** Модуль `src/file/course-file.js`, без DOM.
    - `courseDocument(layout, {build, edited})` — документ: `format: "motogymkhana-course"`, `version: 1`, `build`, `edited`, затем раскладка (`recipe`, `seed`, `elements`). Элементы пишутся у любой трассы, и у несдвинутой: seed повторяет трассу только в одной сборке (ADR 0009). `readCourseFile(text)` возвращает раскладку или ошибку-фразу для пользователя: не JSON, чужой формат, нет версии, версия новее этой сборки, элементы, рецепт или seed не читаются. Файл только с рецептом и seed (без `elements`) открывается как трасса, которую эта сборка генерирует для них.
    - `conesCsv(course)` — по строке на физический конус в порядке расстановки: старт, каждый элемент с конусами разворота связки после него, финиш. Колонки: №, где (элемент «N. Тип», связка, старт или финиш), № в таблице карточки, высота, цвет (синий — слева, красный — справа, у низкого «любой»), X и Y от опорного угла с точностью 0,1 м. Разделитель — точка с запятой, десятичная запятая, в начале BOM: так таблица с русской локалью сразу раскладывает по колонкам.
    - Интерфейс. В рецепте блок «Файл трассы»: «Сохранить .json», «Конусы .csv» (скачивание прямо по нажатию), «Открыть .json» (выбор файла); где устройство умеет делиться файлами такого типа — ещё «Отправить .json» и «Отправить .csv». Открытый файл ставит в форму свой рецепт и seed, а свои элементы — поверх сгенерированной трассы, как «↶»: если эта сборка по тому же seed строит другую трассу, показывается трасса из файла как трасса с правками; если не строит вовсе — трасса из файла всё равно показывается. Трасса с правками того же рецепта и seed, которую заменил файл, уходит в «↶». Ошибка файла пишется под кнопками.
