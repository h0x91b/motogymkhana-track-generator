# Модуль 5: Модель трассы

5. **Модель трассы (канонические данные).**
   - Площадка, элементы (id, тип, параметры, ось как число 0…7 × 45° (в «Правке» и с половинным шагом, 0,5 = 22,5°, тогда признак `offLattice`, ADR 0019), признак отражения, id якорного конуса, номер по порядку прохождения).
   - Конусы (id, координаты, высокий или низкий, цвет).
   - Прохождения (ссылка на конус или пару конусов ворот, сторона конуса, угол вращения; у прохождения элемента — его id, у конуса разворота — связка `connector: {from, to}`).
   - Маршрут (упорядоченные прохождения, ломаные связок для отрисовки, конусы разворота связок, линия старта и финиша).
   - Система координат: метры, начало в опорном углу (левый нижний на плане), X вдоль ширины вправо, Y вдоль длины вверх, углы против часовой стрелки от +X. Инверсия Y только при отрисовке.
   - Все координаты конусов кратны 0,5 м, а якоря — целые метры. Канонически они хранятся целыми числами полуметров, чтобы исключить дрейф чисел с плавающей точкой. Исключение — конусы элемента вне решётки (`offLattice`, повёрнут в «Правке» на 22,5° и т. п., ADR 0019) и линии старта или финиша за ним: их полуметры — не целые числа, якорь элемента всё равно на целых метрах.
   - Сторона конуса — единственное первичное поле, цвет выводится из неё (слева — синий, справа — красный) и отдельно не хранится.
   - Каноническая сериализация (стабильный порядок id и ключей) используется, чтобы сравнить трассу с показанной, и в тестах повторяемости.
