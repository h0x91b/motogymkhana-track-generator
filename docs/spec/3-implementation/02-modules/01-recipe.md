# Модуль 1: Рецепт

1. **Рецепт.** Превращает значения формы в нормализованный рецепт или список ошибок по полям. Поля:
   - ширина и длина площадки: целые метры, разумный диапазон порядка 10–100;
   - вырезы и препятствия (`blocked`, ADR 0015): до 8 прямоугольников площадки, где трассы нет, — вырез (там нет асфальта: П-образная площадка — прямоугольник с вырезом) или препятствие на асфальте (машина, столб, островок). Каждый — вид, X и Y угла, ближнего к «A (0,0)», и размеры по X и по Y, целые метры, целиком в прямоугольнике площадки. У каждого может быть свой отступ (`margin`, 0–3 м шагом 0,5, ADR 0022) — сколько свободного асфальта держать от его краёв; без него — отступ от края площадки (`safety.edge`), и тогда в рецепте поля нет. Рецепт без этого поля — без них;
   - число элементов: 1–15;
   - разрешённые типы: непустое подмножество 23 типов (конус слева, конус справа и малый разворот — заполнители, ADR 0024);
   - сложность: лёгкая / средняя / сложная;
   - класс мотоцикла: спорт / крузер (в форме по умолчанию крузер; рецепт без этого поля — под крузер). Задаёт самый тугой поворот связок и разворотов внутри элементов: круг Ø 7,5 м на спорте, Ø 9 м на крузере;
   - форма трассы: открытая / замкнутая / финиш у старта (в форме по умолчанию финиш у старта; сохранённая форма остаётся какой была). Рецепт без формы, сохранённый с прежней галочкой «Замкнутая», читается так: да — замкнутая, нет или поля нет — открытая;
   - паровозик: по трассе едут несколько мотоциклов друг за другом (в форме включён по умолчанию; рецепт без этого поля — без паровозика);
   - безопасность (`safety`, ADR 0014): сколько свободного асфальта держит генератор — выкат вокруг разворотов и петель (`runOff`, 0–5 м шагом 0,5, обычно 5), запас вокруг элемента (`pad`, 0–2 м шагом 0,25, обычно 0,75), свободно у конуса разворота (`coneGap`, 0–3 м шагом 0,5, обычно 1,5 — круг такого радиуса), зазор маршрута в паровозике (`trainGap`, 0–5 м шагом 0,5, обычно 2), отступ от края площадки (`edge`, 0–3 м шагом 0,5, обычно 1; его же держат вырезы и препятствия без своего отступа). 0 выключает правило. В рецепте остаются только значения не по умолчанию, рецепт без поля — по умолчанию, и трасса тогда та же, что без него. В форме — свёрнутая группа «Ещё: безопасность», на схеме расстановки — строка «Безопасность не по умолчанию: …». Выкат и запас каждому элементу можно задать свои в «Правке».

   Seed разбирается отдельно: десятичная запись целого 0…4294967295, ведущие нули нормализуются. Пустое поле, дробь и выход за диапазон считаются ошибкой. Случайное число никогда не подставляется молча.
