# Модуль 9: Приложение и интерфейс

9. **Приложение и интерфейс.**
   - Портретная ориентация основная. Ширина от 320 CSS px без горизонтальной прокрутки. Зоны касания не меньше 44 × 44. Учитываются безопасные области и экранная клавиатура.
   - Почти весь экран занимает трасса. Форма открывается нижней панелью, «Новый seed» — главная кнопка в зоне большого пальца. Галочки типов спрятаны под «Ещё».
   - Ошибка показывается плашкой поверх трассы, упрощение — меткой «влезло K из N» в сводке и разовой подсказкой. Есть переключатель «План / 3D», режим «Расстановка» с «Назад/Дальше» и кнопка «Картинка».
   - «Проезд»: в 3D схематичный мотоцикл проходит весь маршрут с постоянной скоростью (5 м/с), кренясь в поворотах; камера следит за ним с небольшим приближением, текущий элемент подсвечивается с размерами. В паровозике едет колонна из трёх мотоциклов с интервалом 8 м. Пока идёт проезд, над кнопкой есть скорость воспроизведения 1× / 2× / 4× (ускоряется только время, крен остаётся как на 5 м/с); выбор запоминается в localStorage под своим ключом. Пауза сохраняет место, новая трасса, форма и «Расстановка» проезд останавливают.
   - Любое корректное изменение формы перестраивает трассу с задержкой ~300 мс.
   - Последняя форма хранится под одним ключом localStorage с пространством имён и версией (скорость проезда — под вторым). Каждое обращение обёрнуто в try/catch. `localStorage.clear()` никогда не вызывается.
   - Интерфейс на русском: метры, десятичная запятая, градусы. Сборка (коммит и дата) мелко показана рядом с подписью.
