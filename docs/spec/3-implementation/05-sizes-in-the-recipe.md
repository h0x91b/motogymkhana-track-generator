# Размеры элементов в рецепте

Размер по сложности можно заменить заданным размером (ADR 0011): у типа из таблицы ниже под его строкой в «Ещё: типы и размеры элементов» есть кнопка «Размер», под ней — «авто» (диапазон сложности) и значения через 0,5 м. Заданный размер сохраняется в рецепте как `sizes: { тип: { ключ: метры } }`; неотмеченные типы в него не попадают. На стороне площадки генератор берёт ровно заданное значение, на диагонали — ближайшую длину решётки в пределах ±0,25 м (ADR 0005), а если такой нет — ставит элемент только вдоль сторон. Остальные размеры типа по-прежнему вытягиваются из диапазонов сложности. Размеры, где класс мотоцикла задаёт минимум, — ширина разворота и сторона коробки — поднимаются до него; форма предупреждает «мало для мотоцикла», а карточка схемы пишет, сколько взято. Радиус петли восьмёрки больше не задаётся (ADR 0021): рецепт со старым ключом `figure-eight.loop` — например, в файле трассы — читается без него.

| Тип: размер | Значения |
|---|---|
| Прямой слалом: шаг | 3–6 м |
| Офсетный слалом: шаг вдоль оси | 3–7 м |
| Ворота: ширина | 1,5–3,5 м |
| Переставка: смещение | 1,5–4 м |
| Разворот: ширина (не меньше класса) | 8–16 м |
| Восьмёрка: между конусами (петли — по классу мотоцикла, ADR 0021) | 5–12 м |
| Коробка: сторона (не меньше класса) | 8–16 м |
| Малый круг: радиус кольца | 1,5–5 м |
| Тоннель: между воротами | 3,5–6 м |
| Зигзаг: шаг | 2,5–5 м |
| Змейка в коридоре: ширина коридора / шаг перегородок | 3–6 м / 2,5–5 м |
| Замочная скважина: радиус кольца («авто» — по классу мотоцикла: 4 м, круизёр 4,5 м) | 3–4,5 м |
| Месяц: радиус полукруга | 4–8 м |

У быстрого круга размера в рецепте нет: радиус его кольца — постоянные 12 м с площадки.

Карточка элемента начинается со строки «Задано в рецепте: …» (у элемента, которому этот размер поменяли в «Правке», строки нет), сводка под планом перечисляет заданные размеры отмеченных типов (первые два, дальше «ещё N разм.»).
