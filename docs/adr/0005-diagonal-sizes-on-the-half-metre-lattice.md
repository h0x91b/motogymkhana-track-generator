# Diagonal elements take the nearest lattice size, or stay on side axes

Every cone sits on the 0.5 m grid, so an element on a 45° axis is laid out in steps of ΔX = ±ΔY = 0.5 m, i.e. 0.707 m along the diagonal. The difficulty table (SPEC) gives ranges such as "slalom step 3.5–4 m" and single values such as "gate 2 m". We read a range as inclusive and a single value V as "V on the grid", i.e. V ± 0.25 m: on a side axis that admits exactly V, and on a diagonal it admits the √2-lattice length if one falls that close (2 m → 3 steps = 2.12 m). When no diagonal lattice length falls in range for some size of a type at a difficulty — for example a 2.5 m gate, a 6 m figure eight, the hard straight slalom — that type is placed only along the site sides at that difficulty. The setup sheet always shows diagonal sizes as ΔX/ΔY in multiples of 0.5 m, never the irrational diagonal length.

## Considered Options

- Exact single values on diagonals — almost no type could ever go diagonal, losing most of what ADR 0001 allows.
- Off-grid diagonal cones — the true size, but cones would need 0.1 m measurements and the "everything in 0.5 m" rule of the sheet would break.
