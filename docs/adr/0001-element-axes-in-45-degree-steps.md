# Element axes are restricted to multiples of 45°

Courses are set up on asphalt with one tape measure from the reference corner. An element along a site side or on a 45° diagonal needs only its anchor (two measurements); the diagonal is laid out by equal X/Y offsets. Arbitrary angles would need a second anchor per element (four measurements) and accumulate error on large sites, so the generator only places elements at the eight 45° orientations. This also keeps the generator's search space small.

## Considered Options

- 0/90° only — easiest to set up, but courses look grid-like and repetitive.
- Any angle with a second anchor — full freedom, double the measuring work, error stacks up.
- 15° steps — everything except 0/45/90 still needs a second anchor, so it costs as much as "any angle".
