# Генератор трасс мотоджимханы

**Открыть: https://h0x91b.github.io/motogymkhana-track-generator/**

Мобильная страница, которая по размерам площадки, числу элементов, сложности и seed собирает тренировочную трассу мотоджимханы, показывает её планом сверху и в 3D и отдаёт серию PNG со схемой расстановки конусов — чтобы поставить трассу на асфальте одной рулеткой и скинуть её группе в чат.

Один и тот же рецепт + seed в одном браузере дают одну и ту же трассу; трассой делятся картинкой, а не номером.

## Разработка

Нужен только [Bun](https://bun.sh) (зависимостей из npm нет).

```sh
bun test        # тесты генератора и схемы расстановки
bun run dev     # dev-сервер на http://localhost:5173
bun run build   # один самостоятельный dist/index.html
```

Каждый push в `master` прогоняет тесты, собирает страницу и выкладывает её на GitHub Pages (`.github/workflows/pages.yml`).
